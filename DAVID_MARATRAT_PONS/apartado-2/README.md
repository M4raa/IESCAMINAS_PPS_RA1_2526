# 🖥️ Info.sh

Script que muestra información básica del sistema.

## 📋 Funcionalidades

El script extrae y muestra la siguiente información:
1.  **Dirección MAC:** Obtiene la dirección física de la primera interfaz de red.
2.  **Sistema Operativo:** Muestra información del kernel/SO.
3.  **Hostname:** El nombre de red del equipo.
4.  **Usuario Actual:** El usuario que está ejecutando el script.

## 🚀 Uso

```bash
./info.sh
```
